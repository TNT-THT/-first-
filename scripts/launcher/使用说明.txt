OJ AI 网站包使用说明（在自己电脑上使用 AI + API）
================================================

这个压缩包可以在你的电脑上同时运行网站和 API：
网站里的 AI 用你的显卡在浏览器中运行；其他软件可以用 API Key 调用它。
不需要购买服务器，不需要安装 Ollama，也不需要另外安装 Node.js——
运行环境已经内置在压缩包里，解压后双击即可，全程不用打开终端敲命令。
（网站包按电脑系统分四个版本下载，你手里的就是你下载时选的那个版本；
如果启动时提示系统/芯片不对，说明下错了版本，回到网站重新下对应版本即可。）

一、Windows
  1. 把整个压缩包完整解压到一个文件夹（不要只打开压缩包里的单个文件）。
  2. 双击 start-windows.bat。
  3. 黑色窗口会显示「网站口令」和「管理口令」，请先记下来（或拍照保存）。
  4. 浏览器会自动打开 http://127.0.0.1:3000/ ，用「网站口令」登录。
  5. 使用期间保持黑色窗口和网页都打开；关闭任意一个，AI 和 API 都会停止。

二、macOS
  1. 把整个压缩包完整解压。
  2. 双击 start-mac.command（若系统拦截，在“系统设置 → 隐私与安全性”中允许打开）。
  3. 其余步骤同上：记下口令 → 浏览器自动打开 → 用网站口令登录。

二（续）、Linux
  1. 把整个压缩包完整解压。
  2. 双击 start-linux.sh（若被用文本编辑器打开，先右键该文件 → 属性 →
     权限，勾选“允许作为程序执行”，再双击）。
  3. 其余步骤同上：记下口令 → 浏览器自动打开 → 用网站口令登录。

三、在网页里申请 API Key（点一下就能用）
  1. 登录后，点击网页右上角的「API 接入」。
  2. 在「申请 API Key（本机网页）」里点击「申请一把 API Key」。
  3. 完整 Key 只显示一次，立即复制保存。
  4. 在你的软件（支持 OpenAI 兼容接口的都可以）里填写：
       接口地址（Base URL）：http://127.0.0.1:3000/v1
       （只填到 /v1 为止，不要填成 …/v1/chat/completions，
         否则软件获取模型列表时会报 404。）
       API Key：刚刚复制的 Key
       模型：网页「API 接入」里显示的模型名称
     即可开始调用。软件和网页在同一台电脑上使用。

四、注意事项
  - 第一次使用某个 AI 模型时，网页要先联网下载模型（几百 MB 到数 GB），
    这是模型本身的下载，网站包已经完整、不需要再下别的东西；
    下载后会缓存在浏览器里，之后可以离线使用。
  - 请用最新版 Chrome 或 Edge 打开网页（AI 需要浏览器支持显卡加速 WebGPU）。
  - API 只在这台电脑上有效（127.0.0.1），其他电脑访问不了，这是为了安全。
  - 不要把黑色窗口里显示的两个口令、申请到的 API Key 发给别人，
    也不要把解压文件夹里的 .local-api.json 文件分享出去。
  - 管理员功能：登录后点击网页右上角「API 管理」，用「管理口令」验证，
    就可以调参数、管理（撤销）API Key；没记下管理口令时，可在解压文件夹的
    .local-api.json 里查看 API_ADMIN_PASSWORD（不要把这个文件发给别人）。

五、后备方式（只有网页聊天，没有 API）
  如果一键启动遇到问题，也可以只打开网页聊天版：
  - Windows：双击 start-windows-static.bat。
  - macOS：在解压后的文件夹打开终端，运行 python3 serve-site.py。
  - Linux：同 macOS（后备方式）；一键启动本机 API 请用上面的 start-linux.sh。
  后备方式打开的网页只能自己聊天，不能申请 API Key。

六、万一启动失败
  - 先确认压缩包已完整解压（不要在压缩包里直接双击文件）。
  - 把黑色窗口里最后几行报错截图，反馈给网站提供者即可。
