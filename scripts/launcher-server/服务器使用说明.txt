局域网服务器版（Windows）使用说明
================================

这台电脑负责真正运行模型；同一个局域网（同一个路由器/Wi-Fi）里的其他人，
只需要用浏览器打开服务器地址就能聊天，计算都在这台电脑上完成，
结果再传回各自的网页。不需要在每台电脑上分别装软件或下模型。

一、启动
1. 解压 server-win-x64.zip 到一个普通文件夹（不要放在系统盘的 Program Files 里）。
2. 双击 start-server.bat。窗口里会显示几个 http://192.168.x.x:3000/ 这样的地址。
3. 局域网里其他人用手机/电脑浏览器打开其中一个地址即可使用。
   本机自测地址：http://127.0.0.1:3000/
4. 用完直接关闭那个黑色窗口即停止服务。

二、首次配置（重要）
- 普通聊天打开就能用，不需要注册登录（注册账号只是把自己的对话和设定
  按账号存在服务器上，换设备登录同一账号能接着用；模型是大家共用的）。
- 想让服务器跑模型，二选一：
  A. 本机大模型：用管理员口令登录网页右上角/API 接入里的管理员控制台，
     在“本机大模型”里下载并加载一个 GGUF 模型（模型下到本机 data 目录）。
  B. 云端上游：在解压目录新建 server.env，填写：
       LLM_BASE_URL=https://你的上游地址/v1
       LLM_API_KEY=你的密钥
       LLM_MODEL=模型名
- 管理员口令（下载/加载模型、API 控制台等管理操作要用，至少 16 位）：
  在 server.env 里加一行：  API_ADMIN_PASSWORD=换成你自己的长口令
  改完 server.env 需要关掉窗口重新双击 start-server.bat 才生效。
- 建议在 server.env 里固定一行 SESSION_SECRET=一串随机长字符串，
  否则服务器每次重启后，已登录的账号需要重新登录一次。

三、常见问题
- 别人打不开：先确认在同一局域网；再检查 Windows 防火墙是否放行了
  Node.js/该端口（首次启动时系统弹窗请点“允许”）；路由器不要开“AP 隔离”。
- 端口被占用：在 server.env 里加一行 PORT=3100（换个数字），重启后
  访问地址里的 3000 也要换成 3100。
- 数据存放：账号、对话同步数据与下载的模型都存在解压目录的 data\ 里，
  备份/迁移时整个文件夹一起拷走即可。
