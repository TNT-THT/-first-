API Key 管理

          
为每位用户或应用单独创建一把 Key 并安全分发；可随时单独撤销。本站没有个人账号体系，也不会自动记录 Key 的真实使用者。

          

            
已创建的密钥只显示名称、创建时间和末四位。网站不保存明文；创建后请立即复制，并只放在你控制的后端或受信任的 API 客户端中。
