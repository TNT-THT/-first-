支持 OpenAI 兼容标准参数和上游自定义 JSON 参数。模型、消息、temperature、输出 token 上限和流式模式由单独字段控制；API_MAX_TOKENS 始终是硬上限。API 调用方可按请求覆盖额外默认值。

            
            
            
每行填写一个网站来源（如 https://pd.geneluo.fun，不要带后面的路径），保存后立即生效。名单里的网页可以在浏览器中跨域调用本 API（仍必须填写有效 API Key；浏览器可能还会询问本地网络访问权限，请点允许）。本机版默认已包含本站与纸上谈兵游戏站。只添加你信任的网站：在名单网站中输入的 Key 会被该网站的网页代码接触到。填 * 表示允许任意网站调用（不建议）；清空则只有本站网页能用。支持 https://*.example.com 形式的子域通配。
