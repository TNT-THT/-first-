LLM托管平台——天蓝色1.0（独立软件）使用说明
================================================

这是什么
--------
一个装在自己电脑上的大模型托管平台，双击即可使用，不需要预先安装任何东西：
- 浏览器里运行 39 个开源小模型（0.5B～70B，WebGPU），和原网页版功能完全一致；
- 本机原生运行 27B～671B 级开源大模型（llama.cpp 引擎）：Qwen3.8-27B、Qwen3-32B、
  Llama-3.3-70B、Llama-4-Scout-109B、Qwen3-235B、Llama-3.1-405B、DeepSeek-R1-671B 等 11 个；
- 带 OpenAI 兼容 API（/v1）、API Key 管理、管理员面板与用量统计。

怎么用
------
1. 推荐：直接双击「LLM托管平台-天蓝色1.0.exe」，会弹出一个黑色窗口并自动打开浏览器。
   关闭黑色窗口即停止服务。
2. 解压版：完整压缩包里还有 app/ 文件夹（需要电脑装有 Node.js 18 以上），
   在 app/ 里运行 `node standalone/launcher.mjs` 效果相同。
3. 浏览器打开后，先用窗口里显示的「网站口令」登录（口令保存在数据目录的
   credentials.json 中，首次自动生成、之后不变）。

从 Hugging Face 添加任意模型（多格式）
--------------------------------------
内置的 11 个只是精选。想用别的模型：打开「API 接入 → 本机大模型」里的
「Hugging Face 模型桥接」，搜模型名或粘贴 Hugging Face 链接，点「一键使用」：
- GGUF 格式：自动下载到本机运行；
- Safetensors / PyTorch（Transformers）格式：自动转成 GGUF 后运行（首次用先点
  「一键准备格式转换工具」，要装 Python 转换环境，约数百 MB，只装一次；
  电脑需装有 Python 3.10 以上与 Git）；
- ONNX / MLX / AWQ / GPTQ 等特殊格式：点「本地运行（Python）」把原格式下载到本地，
  用内置 Python 运行时直接推理（需先点「一键准备本地运行时」，与格式转换共用
  同一个 Python 环境，约数百 MB，只装一次；CPU 上大模型会慢，但保证纯本地能跑）。
- 每个模型面板都还有「云端使用」选项（需先在桥接区填入免费的 Hugging Face Token），
  云端只是方便切换的选项：切回本地是默认优先路线，本地文件不会被删，随时可切回。
添加好的模型会出现在聊天页的模型选择里（原有下拉框不变），API 与用量统计同样可用。

网页搜索
--------
软件版的联网检索走服务端网页搜索：会真正去搜索引擎查网页并抓取正文，
回答里带 [编号] 出处。想效果更好，可在启动前设置环境变量
TAVILY_API_KEY / BRAVE_SEARCH_KEY / BING_SEARCH_KEY 任一（不设也能用免密钥兜底）。

跑大模型（27B～671B）
--------------------
1. 登录后点右上角「API 接入」，拉到「本机大模型（llama.cpp 独立引擎）」。
2. 第一次用：先在下方「管理员控制面板」输入窗口里显示的「管理口令」验证一次
   （只验证这一次，之后关掉面板、刷新页面都不用再验证；点「锁定管理面板」才会退出）。
3. 点「准备 llama.cpp 运行库」（自动从官方 GitHub 下载，约几十 MB）。
4. 在想用的模型一行点「获取量化列表」，选一档量化（会标注大小和约需内存），点「下载所选量化」。
   权重从 Hugging Face 下载到数据目录，断网后重新点下载可以续传。
5. 下载完点「加载」，再回到聊天页，在模型下拉框的「本机大模型」分组里选它就能对话；
   也可以用 API 调用（模型名就是列表里的英文 ID，如 DeepSeek-R1-671B）。

内存提醒（内存+显存合计，越大越稳）
----------------------------------
- 27B～32B（Q4 量化）：约 20～24 GB
- 70B～72B（Q4 量化）：约 45～50 GB
- 109B～141B（Q4 量化）：约 65～90 GB；低比特量化约 35～55 GB
- 235B（Q4 量化）：约 140 GB；Q2 量化约 85 GB
- 405B（Q4 量化）：约 230 GB；低比特约 85～120 GB
- 671B（Q4 量化）：约 400 GB；UD-IQ1 等低比特约 180～220 GB
内存不够时请选更小的量化；「GPU 卸载层数」默认 0（纯 CPU 最稳），显存充足时可调大加速。

数据放哪
--------
- exe 同目录的 LLMHost-SkyBlue-Data/（不可写时在 %LOCALAPPDATA%\LLMHost-SkyBlue\）：
  credentials.json（口令）、native/models/（大模型权重）、native/bin/（llama.cpp）、
  api-keys.json / usage-stats.json（API Key 与用量统计）。
- 想彻底清除：关掉程序后删掉这个数据文件夹即可（权重很大，删前请确认）。

常见问题
--------
- 双击没反应/被杀毒软件拦截：单文件程序未做商业签名，部分杀毒软件会误报；
  可改用完整压缩包里的 app/ 解压版，或把 exe 加入白名单。
- 端口被占用：会自动从 3210 顺延找空闲端口，看黑色窗口打印的地址。
- 大模型加载很慢：几百 GB 权重首次加载需要几分钟，属正常；加载状态会在面板里显示。
- 想换端口/不自动开浏览器：设置环境变量 OJ_PORT、OJ_NO_OPEN_BROWSER=1 后再启动。
